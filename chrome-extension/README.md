# Studysis Chrome 扩展

## 概述

这个扩展负责 Studysis 的浏览器侧接入与侧边栏界面，目标是服务于 B 站学习视频总结。

当前职责包括：

- 检测当前 B 站学习视频页面
- 收集页面级元数据
- 尽早接入 B 站页面数据
- 在可用时抓取官方字幕相关信息
- 把快照发送给本地后端
- 在侧边栏展示总览、章节卡片和备考考点
- 支持点击时间点回跳视频

## 目录结构

```text
chrome-extension/
|- manifest.json
|- background.js

|- sidepanel.html
|- sidepanel.css
|- sidepanel.js
|- assets/
|  `- icons/
`- README.md
```

## 在 Chrome 中加载

1. 打开 `chrome://extensions/`
2. 开启开发者模式
3. 点击“加载已解压的扩展程序”
4. 选择 `chrome-extension/` 目录

当你修改了 `manifest.json` 或脚本文件后，请重新加载扩展。

## 后端依赖

默认后端接口地址：

```text
POST http://127.0.0.1:8000/api/v1/collect/segment
```

测试扩展前，请确保本地后端已经启动。

## 当前抓取策略

扩展已经不再使用早期那种浏览器端高频重轮询逻辑。

现在更偏向事件驱动：

- 页面加载时初始化
- 绑定当前视频元素
- 标准化会话标识
- 收集页面上下文
- 收集字幕相关页面数据
- 在关键状态变化时发送快照
- 通过轮询后端会话详情来刷新侧边栏展示

## B 站相关说明

当前代码主要围绕 B 站学习视频做优化：

- `page-hook.js` 运行在页面上下文
- `content.js` 接收并标准化字幕与调试数据
- 官方字幕元数据可传给后端，用于后续落盘与分析

## 侧边栏体验

当前侧边栏行为如下：

- 速览总结先显示加载态，再显示结果
- 章节区域在分析完成前显示加载态
- 备考考点区域在结果完成前显示加载态
- 点击跳转按钮可把视频定位到对应时间点

## 权限说明

当前扩展使用了这些权限：

- `storage`
- `tabs`
- `sidePanel`
- 较宽的 host permissions，用于本地后端访问和页面接入

如果后续准备公开发布，请重新检查 `manifest.json` 中的权限范围并尽量收紧。
